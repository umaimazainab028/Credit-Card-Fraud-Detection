# Credit Card Fraud Detection

## Project Description
A Machine Learning project that detects potentially fraudulent credit card transactions using classification models.

## Dataset Source
MLG-ULB. *Credit Card Fraud Detection Dataset*. Kaggle.

[Credit Card Fraud Detection – Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

## Tools Used
- Python
- Pandas and NumPy
- Scikit-learn
- Google Colab

## Project Files
- `Credit_Card_Fraud_Detection.ipynb` — Data preprocessing, model training, evaluation, and tuning.
- `fraud_detection_results.csv` — Model evaluation results.
- `README.md` — Project documentation.

## How to Run
1. Download or clone this repository.
2. Open the notebook in [Google Colab](https://colab.research.google.com/).
3. Upload the Kaggle dataset and update its file path if needed.
4. Run all cells in order to train and evaluate the models.

## Results
- **Highest Recall:** Logistic Regression — 0.9184
- **Highest Precision:** Tuned Random Forest — 0.8119
- **Highest ROC-AUC:** Random Forest — 0.9723
